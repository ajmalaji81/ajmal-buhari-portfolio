Personal Portfolio Website

This repository hosts the source code for a professional personal portfolio website highlighting expertise in MIS management, data integrity, and workflow automation.

Overview

The portfolio is structured to showcase professional experience, core competencies, and technical proficiencies, including:

Advanced Excel & Reporting:

Managing sales registers, custom number formatting, VLOOKUP, pivot tables, and formula automation.

Workflow Automation: 

Streamlining operational processes using automation tools such as n8n.

Administrative & Data Management: 

Ensuring high data integrity and efficient distribution frameworks.

Technologies Used HTML5 & CSS3: For structuring and styling a clean, responsive layout.

Font Awesome: For professional iconography.

Google Fonts: Utilizing Plus Jakarta Sans and Fira Code typography.

Project Structure
index.html: The core single-page application containing all sections including the hero summary, core expertise, experience, and contact options.

Deployment
This site is built and published automatically via GitHub Pages from the main branch.
